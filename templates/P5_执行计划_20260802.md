# P5 执行计划（2026-08-02 修正版）


## 一、P5 概况

P5 共 18 个标号（P5-1 到 P5-18），全部集中在 P5 一张大表格——uHCC 一线治疗方案对比表（化疗 / 靶向 / 免疫 / 靶免联合）。


## 二、执行步骤（3 步，按正确顺序）

### 步骤 1：视觉理解 PPT

**目标**：看 PPT 第 5 页，理解每个标号对应的视觉内容和文本内容。

对每个标号执行：
- 看 PPT 中该标号出现在哪个位置（表格行/列、标题、文字框）
- 理解该位置的视觉信息（表格结构、颜色、布局）
- 理解该位置的文本信息（方案名称、药物、关键研究、疗效数据）
- 记录：**标号 → PPT 位置 → 视觉内容 + 文本内容**

**输出**：Pn-x 的 PPT 视觉理解描述（作为 C 列的原始素材）

**例子（P5-2 标号 2）**：
```
标号 2 出现在 P5 表格 Row 1 第 3 列「药物」栏
视觉：表格第一行，类型=化疗方案，方案名称=FOLFOX方案
文本：药物=奥沙利铂+5-FU+亚叶酸钙，关键研究=EACH，疗效=随访7个月
```

### 步骤 2：视觉理解 PDF 的 Highlight

**目标**：对每个 PDF 文件，找出已存在的 highlight 内容，理解它与 PPT 中引文标号的位置是否对齐。

对每个标号执行：
- 打开 PDF 中已有的 highlight 图
- 理解 highlight 区域的内容（文本、表格、图表）
- 判断：这个 highlight 是否对应 PPT 中该标号要表达的信息？
- 如果不对齐：记录差距，作为后续修正的依据

**输出**：Pn-x 的 PDF highlight 视觉理解 + 与 PPT 标号的对齐检查

### 步骤 3：校验对齐（C 列到 H 列）

**目标**：五方对账，确保所有信息一致。

对每个标号校验以下 5 个维度的对齐关系：

| 维度 | 来源 | 说明 |
|------|------|------|
| ① PPT 引文位置视觉理解 + 文本理解 | 步骤 1 的输出 | 标号在 PPT 中的位置、视觉结构、文本内容 |
| ② PPT 中的文献引用字段 | 表格 D 列 | 作者、期刊、年份等完整引用字段 |
| ③ PDF 全文内容 | pdf_understand.py 的 Docling 解析 | PDF 的文本、表格、图片的完整内容 |
| ④ PDF 的 Highlight 区域 | 步骤 2 的输出 | highlight 区域的内容、位置、是否对齐 |
| ⑤ H 列（PPT 与 PDF 内容对齐 + 文献信息 + 下载链接） | 表格 H 列 | 最终要写入飞书的内容 |

**校验逻辑**：
- ① 必须与 ③ 匹配（PPT 引文位置 → PDF 内容）
- ② 必须与 ③ 匹配（PPT 引用字段 → PDF 文献）
- ④ 必须与 ③ 匹配（highlight 区域 → PDF 内容）
- ⑤ 必须包含 ①+②+④ 的所有信息

**如果发现问题**：
- PPT 视觉理解与 PDF 内容不匹配 → 重新标注 highlight
- PDF 标注不对齐 → 调整 highlight 区域（用 bbox 精确高亮）
- H 列信息不完整 → 补充
