# OCR 增强功能立项方案

日期: 2026-09-07
仓库: via54Medit (main @ e5b5042)
关联交付: docs/rsv_delivery_2026-09-07/ (README、rsv_sentences_official.tsv、official_ocr_comparison.json)

## 1. 项目背景

2026-09-07 RSV highlight 交付中，171 句基准经官方验证器回归后出现两类缺口：17 句整页无文字层的 OCR 句子无法被 `verify_sentence_set.py` 复现；另有 12 句落在「页含少量文字层(页眉/页码) + 正文为图像」的混合页，被误报 NOT FOUND。对 12 个乱码/图片型 PDF 用官方 `hl_ocr_band.py` 重放，29 句仅定位成功 4 句（P8-10 2/3、P9-10 1/3、P21-3 1/2），annotations 只生成 10 处，而当日交付为 97 处。官方工具的 OCR 通道在单栏/简单双栏英文可读图片上可用，对 CSR 扫描表格、PubMed 打印件、中文双栏等复杂版面无法自动复现。

本立项方案将官方工具的 OCR 通道从「词带短语窗口」升级为与文本层同级的「整句定位」，并补齐版面分析与验证器区域级判定，使 171 句基准可整体复现。

## 2. 现状与问题定位

| 模块 | 现状实现 | 失效场景 |
|---|---|---|
| `hl_lib.locate_sentence` | 文本层字符流 norm 匹配，四级回退（精确 → 连字符自愈 → 标点脱敏 → 首尾锚点） | 仅限文字层，无 OCR 路径 |
| `hl_ocr_band.py` | tesseract TSV → `split_cols` 分栏 → 列词流 `find(start/end 短语)` → 行 band quads | 整句只有起点或 end 失配时越界；跨栏/断词/表格序乱 |
| `verify_sentence_set.py` | 页级可读性判定：整页无 CJK/字母才算 OCR 页 | 混合页（有页眉文字层）正文图像句子判 NOT FOUND |

对照数据（`official_ocr_comparison.json`，12 个 OCR 文件共 29 句）：

| 文件 | official placed | official annots | today annots |
|---|---|---|---|
| P8-10 | 2/3 | 5 | 10 |
| P9-10 | 1/3 | 2 | 8 |
| P21-3 | 1/2 | 3 | 6 |
| P3-2/P3-3/P6-1/P8-4 | 0 | 0 | 7/10/16/8 |
| P15-3/P15-4/P23-3 | 0 | 0 | 8/5/4 |
| P27-2/P27-3 | 0 | 0 | 9/6 |

失败根因按文件归类：P3-2/P3-3/P6-1/P8-4 为中文 PDFTron 乱码（OCR 词序与原文差异大）；P15-3/P23-3 为 CSR 357 页表格版面；P15-4 为 CT.gov 图片页；P27-2/P27-3 为 PubMed 打印件/JGIM 乱码。

## 3. 立项范围

按 README §3 建议，拆为三个增强项，均落在 `scripts/hl_v3_final/`：

- **E1 OCR 整句定位**：`hl_ocr_band.py` 支持整句 norm 匹配，与 `hl_lib.locate_sentence` 的回退语义对齐。
- **E2 版面分析**：新增布局区域识别，排除页眉/页脚，表格区域单独处理，中文 chi_sim 双栏按字符宽度聚类。
- **E3 区域级判定**：`verify_sentence_set.py` 对混合页改为「正文区无文字层即走 OCR 通道」，输出 `flag=mixed`，不再误报 NOT FOUND。

不在本次范围：文本层定位算法本身、三模态标注格式、745 句历史集重构。

## 4. 技术方案

### E1 OCR 整句定位

在 `hl_ocr_band.py` 内新增整句匹配路径，保留现有 start/end 短语窗口作为回退。

1. 词流规范化：复用 `hl_lib.canon`/`canon_keys` 的字符规范化语义（全半角、连字、变音符），将 OCR 词流逐词 canonical 后拼接；OCR 特有噪声（插入的标点碎片词、`|`、引号）在规范化阶段剔除。
2. 整句匹配入口 `locate_in_ocr(col_tokens, sentence_norm)`：先做精确子串匹配；失败时按 `hl_lib.locate_sentence` 的回退顺序，实现「去标点匹配」与「首尾锚点匹配」（锚点长度按 OCR 容差放宽到 10 字符），保证跨行断词、中间插入统计片段时不整体失败。
3. 命中后沿用现有行聚合逻辑（tesseract `line_num` 分 band）生成 quads；仅当整句路径不命中时才回退到 `--start/--end` 短语窗口模式，保证不破坏 P8-10/P9-10/P21-3 已有成功案例。
4. CLI 增加 `--sentence "整句文本"` 参数；`--replace-page` 语义不变，便于回归。

### E2 版面分析

新增 `layout.py`（OCR 通道共享），从 tesseract TSV 的行/词坐标构建页面区域模型 `page_zones`，返回有序区域列表，替代现有单一 `split_cols`。

1. 页眉/页脚排除：对 y 直方图顶部/底部 8% 且文字特征为 running head（居中或左右对称短串）或纯页码的行整组剔除，避免其混入阅读序导致整句失配或越界覆盖。
2. 表格区域专用：检测规则竖线与行 x 间断；表格区不做全文阅读序拼接，改为逐 cell 行内匹配，服务 CSR 表注、结果表句子的定位。
3. 中文双栏：当页面含 CJK 字符时，分栏依据从「词 x 中点」改为「字符级 x 聚类 + 栏间隙投影」，避免中英混排下左右栏互相污染；语言标签 `chi_sim` 由调用方传入，规则与 `eng` 路径并存。
4. 区域产出顺序：正文左栏 → 正文右栏 → 表格（按视觉位置），最终 band 高亮限制在命中区域内部，与现有「不跨栏」约束一致。

### E3 区域级判定

修改 `verify_sentence_set.py` 的页级可读性判定为区域级：

1. 对每个文本层页，用 `page_char_stream` 取字符 bbox 分布；正文区（去掉顶部/底部各 10% 与左右页边距后）无有效字符、但整页存在少量文字（页眉/页码/脚注）时，判为 `flag=mixed` 的 OCR 页。
2. 判定结果写入汇总：混合页句子计入 OCR 通道计数，归类为 `MIXED (OCR 通道)`，不再落入 NOT FOUND；文件状态按「文本层 OK + OCR 通道」合计输出。
3. TSV 侧不变，沿用现有 file/page/type/flag/text 格式，flag 列新增可选值 `mixed`，README 中补充取值说明。

## 7. 风险与依赖

- 环境差异：`hl_ocr_band.py` 默认 tesseract 路径为 macOS 绝对路径，Windows 下需 `TESSERACT` 环境变量指向 `vm/tools/bin/tesseract.cmd`，并在 CI/文档中固化。
- 中文 OCR 精度：PDFTron 乱码 + chi_sim 的识别噪声可能使整句精确匹配失败，M1 首尾锚点容差需在 P3-2/P6-1 等文件上单独校准。
- 表格版面复杂：CSR 357 页表注跨行/合并单元格时，M2 的 cell 内匹配可能退化为行内定位，需在 P15-3 预留 `--row-only` 兜底。
- 回归口径：新增 flag=mixed 只影响分类输出，不改 TSV 句子本身，确保 171 句清单与既有交付文件 diff 稳定。

## 8. 结论

OCR 通道的缺口集中在「整句匹配缺失 + 版面模型过简 + 验证器页级判定」三处，均可用现有代码基座增量补齐。落地后 171 句基准可做到文本层与 OCR 通道全量复现，官方验证器与当日交付对齐，问题不再依赖人工逐页确认。

## 10. M3 区域级判定结果 (2026-09-07)

| 判定 | 条件 | 路由 |
|---|---|---|

## 12. 中文乱码文件视觉校准 (2026-09-07)

### 诊断结论

4 个中文文件实为 2 篇文献：P3-2/P6-1/P8-4 同属《中国儿童呼吸道合胞病毒感染诊疗及预防指南(2024 医生版)》(3 个下载版本, 各 10 页), P3-3 为谢正德等 2022 综述(5 页)。渲染完全正常(300dpi OCR 中文可读率 65-80%)，但文字层不可用：全部字体为方正书版(FzBookMaker)私有 Type1 子集，无 ToUnicode，glyph 名 `G21..`、Encoding 私有映射——字符→Unicode 映射在字体层丢失，无法从 PDF 内部无损重建（尝试解析 CFF charset 确认无 uni/cid 命名）。

### 视觉校准方法 (mmx VLM)

对 4 个目标页渲染 300dpi，按纵向 6 带(重叠 3%)转录整页文字，用「规范查询句 + 最长公共子串 + 前/尾 15 字包含探测」定位并确认句子。逐句以 VLM 转录为准提取实际印刷句。全部 8 句确认。

### 验证说明
