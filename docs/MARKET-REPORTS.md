## 报告模板 (TalkMED AgentPilot 风格)

每份报告 7 章节结构:
1. 全球市场总览
2. 已上市药物深度分析
3. 急性药市场
4. 中国市场专项
5. 在研管线与新型靶点
6. 投资关注点 & 趋势预测
7. 数据来源与方法学说明

每份报告含:
- **8+ SVG 图表** (折线/饼/气泡/甘特/时间线)
- **4+ 数据洞察** (💡 紫色)
- **3+ 投资判断** (✅ 绿色)
- **风险提示** (⚠️ 红色)
- **整体结论** + 3 档配置建议
- **11+ 数据源** (Coherent / FMI / Data Bridge / Grand View / Takeda / Amgen / CPA / CRA / Evaluate / CT.gov / FDA Orange Book)

## 数据源优先级 (2026 优先)

1. **商业市场报告**: Coherent Market Insights, Future Market Insights, Data Bridge, Grand View
2. **公司财务**: Takeda / Amgen / Novartis 年报
3. **中国源**: 中国药学会 (CPA), 中华医学会 (CRA), 国家医保局
4. **在研管线**: ClinicalTrials.gov 2026
5. **仿制**: FDA Orange Book

## 方法学

- **数据范围**: 2023-2026 实际/预测, **2026 优先**
- **标注**: 每个数据点附"来源 + 截止日期"
- **预测值**: 标记 (估) 或 (F) 区别于实际
- **不确定性**: 2026 含 H2 预测成分, **不构成投资建议**
