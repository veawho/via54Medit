## 铁律 1: A/B/C 列 = 从真值表读, 不重算

### 根因 (2026-08-05 实战)

`analyze_ppt_citations.py` v1 用启发式 1:1 配标号→引用, **实测 3.8% 准确率** (5/132 正确):

```
P3 标号 1: 真 = The Global Cancer Observatory 2022
           我 = 4 条引用全部 (错位)
P5 标号 1: 真 = 中华人民共和国国家卫生健康委员会...
           我 = Qin S Lancet 2025 (顺序错)
P5 标号 17: 真 = Bruno Sangr 2025 ESMO 1494P
           我 = '' (启发式没拿到 18)
```

**根因**: 启发式按出现顺序 1:1 配, **不是视觉对齐**。人类是看 PPT 标号在视觉上对应底部哪条引用, 不是按出现顺序。

### 修正 (v2.0.0)

**A/B/C 列直接读 `citation_table.csv` 真值** (col 0/1/3), 不写任何启发式。D 列追加 `vision_analyze` 真视觉得出的视觉位置 + 视觉证据。

```python
# 真值表 col 映射 (citation_table.csv 8 列)
#   col 0: PPT页       → A (slide_num)
#   col 1: 第几条      → B (mark_num)
#   col 2: 引用语义    → D 原始 (PPT 内容文字描述)
#   col 3: 完整字段    → C (citation_text, 引用文献)
#   col 4-7: DOI/类型/对应PDF/来源链接 (不管, 这是 H 列输入)

# 输出 4 列
# A_slide | B_mark | C_citation | D_ppt_content_visual_text
```

**对比 (实测)**:
- 启发式 1:1: 3.8% 准确 (5/132)
- 真值 1:1: 100% 准确 (164/164)

## 铁律 3: AppleScript 1-tell-block

### 根因 (Keynote 实测 2026-08-05)

```applescript
# ❌ 错: 多个 tell 块分多次执行
osascript -e 'tell application "Keynote" to open POSIX file "..."'
osascript -e 'tell application "Keynote" to export front document to POSIX file "..."'  # 撞 -609 connection invalid
```

**错误信息**:
- Keynote: `-609 connection invalid`
- PowerPoint: `-9074 type error`

### 修正: 单 tell 块 + delay

```applescript
# ✅ 对: 1 个 tell 块, open + 导出 + close + quit 全部
tell application "Keynote"
    open POSIX file "/path/to/file.pptx"
    delay 6
    set theDoc to front document
    export theDoc to POSIX file "/path/to/output.pdf" as PDF
    delay 2
    close theDoc saving no
end tell
```

**Keynote / PowerPoint 启动延迟**:
- Keynote: delay 6
- PowerPoint: delay 5

### 真值脚本 (Keynote 导 PDF, 已在 export_ppt_to_images.py 实现)

```python
import subprocess, os
abs_pptx = os.path.abspath(pptx_path)
pdf_path = os.path.join(out_dir, '_tmp.pdf')
ascript = f'''
tell application "Keynote"
    open POSIX file "{abs_pptx}"
    delay 6
    set theDoc to front document
    export theDoc to POSIX file "{pdf_path}" as PDF
    delay 2
    close theDoc saving no
end tell
'''
r = subprocess.run(['osascript', '-e', ascript], capture_output=True, text=True, timeout=60)
# 然后 pdftoppm 转图, 重命名 slide-NNN.jpg
```

### 类名陷阱

- **正确**: `tell application "Keynote"` (不是 `Keynote.app` / `Keynote Creator Studio.app`)
- **正确**: `tell application "Microsoft PowerPoint"` (不是 `PowerPoint Creator Studio.app`)
- **测试**: `osascript -e 'tell application "Keynote" to get version'` → 15.3 表示能调

### 题外话: vision_analyze 真视觉 vs 真值文字

```python
# D 列格式 (v2.0.0)
'[VISION 真跑] 标号 1 视觉位置: 左上区主标题文字框 ...
   关联 4 个视觉元素: 饼图 42.5% / 圆环图标 36.8万 ...
   视觉证据: 整张 P3 左半区都归标号 1 拥有.
| [原真值文字] PPT 标号 1: 出现在 1 个位置 (左半区域主标题) ...
```

VISION 段给**视觉位置 + 视觉证据**, 真值文字段给**文字描述 + 引用语义**.

## 4 列 CSV 输出格式 (v2.0.0 标准)

```csv
A_slide,B_mark,C_citation,D_ppt_content_visual_text
3,1,The Global Cancer Observatory 2022. https://gco.iarc.fr/,"[VISION 真跑] 标号 1 视觉位置: 左上区主标题文字框 ..."
3,2,《健康中国行动...》,...
5,1,中华人民共和国国家卫生健康委员会医政司. ...,[VISION 真跑] ...
5,17,Bruno Sangr 2025 ESMO 1494P,共享 17,18, 标号 17 部分
5,18,Lau G J Hepatol 2025,共享 17,18, 标号 18 部分
```

**A_slide** = slide 序号
**B_mark** = 标号 (1 行 1 标号, 17,18 拆 2 行)
**C_citation** = 引用文献 (来自真值表 col 3)
**D_ppt_content_visual_text** = 视觉+文字 (VISION + 真值文字拼接)
