# v2.9.0 GitHub 稳定性方案评估

**版本**: v2.9.0 (2026-08-05)
**目标**: 评估 5 个 GitHub 仓库对 vision_analyze 不稳定问题的解法, 选最适用集成方案.

## 5 仓库对比

| 仓库 | URL | 核心能力 | 适配 v8 难度 |
|------|------|---------|--------------|
| **scanny/python-pptx** | https://github.com/scanny/python-pptx | 100% 确定性 XML 解析 | ✅ 已集成 (v7-v8) |
| **pydantic/pydantic-ai** | https://github.com/pydantic/pydantic-ai | Agent + output_type 结构化 | ✅ 已集成 (v8) |
| **567-labs/instructor** | https://github.com/567-labs/instructor | Pydantic + retry | 中 (手写 OpenAI client) |
| **Blaizzy/mlx-vlm** | https://github.com/Blaizzy/mlx-vlm | Apple Silicon 本地 VLM + JSON Schema constrained | 未来 v8.2 |
| **algorithmicsuperintelligence/optillm** | https://github.com/algorithmicsuperintelligence/optillm | Self-Consistency / Best-of-N / Majority Voting | 未来 v8.3 |

## 关键发现

### scanny/python-pptx (轨道 A 已集成)

- **核心**: 100% 稳定的 PPTX XML 解析
- **优势**: 不依赖 LLM, 跑 100 次结果一致
- **当前使用**: v8 主干轨道, 86.2% 命中真值 C 字段
- **不适用**: 提不了 data_points (柱图/表格/数据点) - 那是图片内的视觉信息

### pydantic/pydantic-ai (Pydantic schema 已集成)

- **核心**: `Agent(output_type=Model)` 强制 LLM 输出固定结构
- **优势**: 字段级 validator, 自动校验, retry, streamed output
- **当前使用**: v8 SlideVision + ChartDataPoint + cap 20
- **限制**: 不能强制 vision 内容正确, 只能保证结构合法

### 567-labs/instructor (备选)

- **核心**: Pydantic structured output 跨多 provider
- **优势**: 跨 OpenAI/Anthropic/Gemini 通用
- **缺点**: 多模态需手写 base64 encode
- **结论**: pydantic-ai 更适合, instructor 不优先

### Blaizzy/mlx-vlm (未来 v8.2)

- **核心**: Apple Silicon 本地 VLM + JSON Schema constrained decoding
- **优势**: 
  - OpenAI-compatible (`/v1/chat/completions`)
  - json_schema 强制 decoding (server-side)
  - Vision feature caching
  - 适合本地可重复测试
- **限制**: 本地模型视觉质量低于顶级云端
- **结论**: v8.2 候选, 替换 vision_analyze

### algorithmicsuperintelligence/optillm (未来 v8.3)

- **核心**: OpenAI-compatible proxy + Self-Consistency / Best-of-N / Majority Voting
- **优势**: 多种 inference-time 方法可组合
- **缺点**: 视觉支持需验证
- **结论**: v8.3 候选, 跑 N=3 voting + majority

## 稳定性方案推荐 (按优先级)

### 1. 立即: scanny/python-pptx (已集成)
- XML 100% 稳定
- v7-v8 算法都在用

### 2. 短期: pydantic/pydantic-ai (已集成)
- `output_type=SlideVision` 强制 schema
- v8 已集成

### 3. 中期: Blaizzy/mlx-vlm (v8.2)
- Apple Silicon 本地 VLM
- JSON Schema constrained decoding
- 替换 vision_analyze, 跑 3 次稳定

### 4. 长期: optillm (v8.3)
- Self-Consistency / Best-of-N / Majority Voting
- 跨多种 LLM provider
- 跑 3 次投票, 多数方胜
