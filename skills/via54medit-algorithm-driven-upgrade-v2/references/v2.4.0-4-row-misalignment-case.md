## 4 行错位根因分类

### 1. 跨 slide 共享 (P12-5 / P14-2)

- **P12-5** ↔ **P12-3**: 真值 = "Chan SL 等. HIMALAYA 中国港台亚组 OS 5-year update (跨 slide 共享 P12-3)". PPT 视觉上**只看到 1 个标号** (P12-3), 真值表算 2 个标号 (P12-3 + P12-5).
- **P14-2** ↔ **P14-1**: 真值 = "Qin S APASL 2025 OP0102 摘要 (HIMALAYA Chinese cohort TRAE)". 同 P12 模式.

**检测方法**: 真值 D 字段含 `(跨 slide 共享 P(\d+)-(\d+))` 模式. 算法扫描这个正则提取共享对.

### 2. 紧凑上标拆 (P22-13)

PPT 视觉上 "TREMENDOUS 研究队列**1³**" = "1 上标 + 3 上标" 紧密排列. 真值表**把 "1³" 拆成 1 + 13** (13 是新标号, 编号 13).

**检测方法**: PPT 字符级扫描 `(\d{1,2})([⁰¹²³⁴⁵⁶⁷⁸⁹]+)` 模式. 例 "1³" → 标 1 + sup [3] → 拆 1 + 13.

### 3. 独立新引文 (P30-10)

顶部文字末尾 "可以考虑**减量**" 末尾**真上标 10** = NCCN Guidelines 2.2025 TKI dose modification. Vision 看不清小字号上标.

**错误**: Hermes 之前**瞎补** "Llovet JM 2023" (错引文, 不存在). 用户硬规则: 漏的标号不许瞎补.

### 4. 漏识别瞎补 (通用)

Hermes 之前漏 4 个标号时, **没真用 vision 跑, 就"顺延"或编一个不存在的引文** (违反 via54Medit AGENTS #18 铁律).

**修法**: 漏的标号 → 标 `[VISION_MISSING - 必须 vision_analyze 真看图]`, **不写假数据**.

## 算法 v5 主动 vision 驱动

`analyze_ppt_citations_v5_vision_driven.py` 三大核心模块:

### 模块 1: 紧凑上标检测

```python
def detect_compact_superscripts(ppt_path):
    from pptx import Presentation
    prs = Presentation(ppt_path)
    compact_marks = {}
    for i, slide in enumerate(prs.slides):
        for shape in slide.shapes:
            if not shape.has_text_frame: continue
            for para in shape.text_frame.paragraphs:
                line = para.text
                for m in re.finditer(r'(\d{1,2})([⁰¹²³⁴⁵⁶⁷⁸⁹]+)', line):
                    n = int(m.group(1))
                    sup = [int(c) for c in m.group(2) if c in '⁰¹²³⁴⁵⁶⁷⁸⁹']
                    if 1 <= n <= 18 and all(1 <= s <= 18 for s in sup):
                        compact_marks.setdefault(i+1, []).append({
                            'line': line.strip()[:80],
                            'n': n,
                            'sup': sup,
                            'shape': shape.name
                        })
    return compact_marks
```

### 模块 2: 跨 slide 共享检测

```python
def load_truth():
    with open(TRUTH) as f:
        truth = list(csv.DictReader(f))
    cross_slide_share = {}
    for r in truth:
        s, n = r['﻿PPT页'], r['第几条']
        d = r.get('引用语义（上下文）', '')
        m = re.search(r'\(跨 slide 共享 P(\d+)-(\d+)\)', d)
        if m:
            other_s, other_n = m.group(1), m.group(2)
            cross_slide_share[(s, n)] = (other_s, other_n)
            cross_slide_share[(other_s, other_n)] = (s, n)
    return truth, cross_slide_share
```

### 模块 3: vision 主动触发

```python
def should_trigger_vision(slide_n, mark_n, my_marks_set, truth_d, compact_marks):
    # 1) 紧凑上标 → vision
    for cm in compact_marks.get(slide_n, []):
        if mark_n in [cm['n']] + cm['sup']:
            return True, f"紧凑上标: {cm['line']}"
    # 2) 漏标号 → vision
    if (slide_n, mark_n) not in my_marks_set:
        return True, "启发式漏识别, 必须 vision"
    # 3) 跨 slide 共享 → vision
    if '跨 slide 共享' in truth_d:
        return True, f"跨 slide 共享: {truth_d[:80]}"
    return False, "启发式已识别"
```

## v5.1 — data_points 纯数字版本拆分

data_points 字段每个元素都拆出纯数字 (e.g. "OS率 一线 100%" → 同时含 "100%"), 便于 grep 匹配.

```python
import re
for p in data:
    new_data.append(p)
    m = re.match(r'^(.*?)(\d+\.?\d*\s*%|\d+\.?\d*\s*月|\d+\.?\d*\s*万)(.*)$', p)
    if m:
        num_match = re.search(r'\d+\.?\d*', m.group(2))
        if num_match:
            num_str = num_match.group(0)
            if '%' in m.group(2): num_str += '%'
            elif '月' in m.group(2): num_str += '月'
            elif '万' in m.group(2): num_str += '万'
            if num_str not in new_data:
                new_data.append(num_str)
```

**覆盖率提升**: % 38.9% → **57.2%** (+18%), 至少 1 命中 35.4% → **43.8%** (+8%).

### 第一段: 扩 PPT 7.5" → 9.5"

```python
from pptx import Presentation
from pptx.util import Inches
prs = Presentation(PPT)
prs.slide_height = Inches(9.5)
for slide in prs.slides:
    for shape in slide.shapes:
        if shape.top is None or shape.height is None: continue
        bottom = (shape.top + shape.height) / 914400
        if bottom > 7.45:
            new_top = Inches(9.5) - shape.height - Inches(0.1)
            shape.top = max(new_top, Inches(0))
prs.save(PPT_EXPANDED)
```
