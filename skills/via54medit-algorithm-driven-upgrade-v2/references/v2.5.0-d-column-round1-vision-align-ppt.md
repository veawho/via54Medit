## v6 算法核心

```python
# analyze_ppt_citations_v6_vision_align.py
def main():
    truth = load_truth()  # 164 - 4 错位 = 160 行
    with open(VISION_D) as f:
        all_v = json.load(f)

    all_pct = all_yue = all_wan = 0
    all_hit_pct = all_hit_yue = all_hit_wan = 0
    all_hit_marks = 0
    miss_list = []

    for r in truth:
        a, n = r['﻿PPT页'], r['第几条']
        truth_d = r['引用语义（上下文）']

        # 提真值 D 所有数字+单位
        truth_pcts = set(re.findall(r'\d+\.?\d*%', truth_d))
        truth_yue = set(re.findall(r'\d+\.?\d*月', truth_d))
        truth_wan = set(re.findall(r'\d+\.?\d*万', truth_d))

        my = all_v.get(a, {}).get(n, {})
        my_d = my.get('data_points', []) if isinstance(my, dict) else []
        my_pcts = set(p for p in my_d if '%' in p)
        my_yue = set(p for p in my_d if '月' in p)
        my_wan = set(p for p in my_d if '万' in p)

        all_pct += len(truth_pcts); all_hit_pct += len(truth_pcts & my_pcts)
        all_yue += len(truth_yue); all_hit_yue += len(truth_yue & my_yue)
        all_wan += len(truth_wan); all_hit_wan += len(truth_wan & my_wan)

        # ≥50% 命中度量
        total_truth = len(truth_pcts) + len(truth_yue) + len(truth_wan)
        if total_truth > 0:
            total_hit = len(truth_pcts & my_pcts) + len(truth_yue & my_yue) + len(truth_wan & my_wan)
            if total_hit / total_truth >= 0.5:
                all_hit_marks += 1
            else:
                miss_list.append((a, n, total_truth, total_hit))

    print(f'% 覆盖: {all_hit_pct}/{all_pct} = {all_hit_pct/max(1,all_pct)*100:.1f}%')
    print(f'月 覆盖: {all_hit_yue}/{all_yue} = {all_hit_yue/max(1,all_yue)*100:.1f}%')
    print(f'万 覆盖: {all_hit_wan}/{all_wan} = {all_hit_wan/max(1,all_wan)*100:.1f}%')
    print(f'≥50% 命中: {all_hit_marks}/160 = {all_hit_marks/160*100:.1f}%')
```

## v6 数据点拆纯数字 pitfall

**实战发现**: 之前 vision D 字段写 `"OS率 一线 100%"`, 跟真值 D 字段的 `"100%"` 字符串**不匹配** (`set` 求交集为空).

**修法** (自动执行):

```python
for s, marks in all_v.items():
    for n, info in marks.items():
        data = info.get('data_points', [])
        new_data = list(data)
        for p in data:
            m = re.match(r'^(.*?)(\d+\.?\d*\s*%|\d+\.?\d*\s*月|\d+\.?\d*\s*万)(.*)$', p)
            if m:
                num_match = re.search(r'\d+\.?\d*', m.group(2))
                if num_match:
                    num_str = num_match.group(0)
                    if '%' in m.group(2): num_str += '%'
                    elif '月' in m.group(2): num_str += '月'
                    elif '万' in m.group(2): num_str += '万'
                    if num_str not in new_data:
                        new_data.append(num_str)
        info['data_points'] = new_data
```

**效果**: 覆盖率 % 覆盖 38.9% → 54.2% (+15%), 至少 1 命中 35.4% → 40.0% (+5%).

## v6 漏标号重跑战法

v6 评估 ≤ 50% 命中 → subagent batch 重跑 (5 个一组, 按 slide 分组).

**subagent prompt 必含**:

```python
"用 vision_analyze 看 PPT 第 N 页 (扩页版). 列 PPT 上**所有数字+单位** (含 Y 轴/X 轴/标签/脚注/风险人数). \
输出 JSON: {slide_N: {mark_N: {position, shape_type, data_points (含纯数字 '6.47月'/'10%'/'45%'), context, related_visual}}}."
```

**subagent 输出至少含**:
- `data_points` list (含纯数字 + 长字符串)
- `position` 位置描述
- `shape_type` 形状类型
- `context` 上下文文字
- `related_visual` 关联视觉元素

**合并时分别处理 6 种结构** (见 `references/v2.5.0-vision-json-6-formats-compat.md`).
