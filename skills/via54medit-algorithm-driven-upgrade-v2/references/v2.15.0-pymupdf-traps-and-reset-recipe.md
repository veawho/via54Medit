## 背景

## 坑 1: os.listdir()[0] 拿到 fallback

**症状**: step3/P3-1 目录有 3 个 PDF: `P3-1_main_GLOBOCAN_2022_Liver_IARC.pdf` + `P3-1_fallback_Bray_2024_GLOBOCAN_2022.pdf` + `P3-1_fallback_GLOBOCAN_2024_China_IARC.pdf`. 用 `pdfs = os.listdir(pn_dir); pdf = pdfs[0]` 拿到 fallback Bray 35 页 (无 China 数据).

**根因**: os.listdir 顺序未定义, 可能 fallback 排第一.

**修法**: 显式 startswith 选 main, 或者更稳: 先删 fallback 再跑.

```python
# 修法 1: 显式选 main
pdfs = [f for f in os.listdir(pn_dir) if f.startswith('P3-1_main') and f.endswith('.pdf')]
pdf = f'{pn_dir}/{pdfs[0]}'

# 修法 2: 删 fallback (更稳)
for f in os.listdir(pn_dir):
    if 'fallback' in f and f.endswith('.pdf'):
        os.remove(f'{pn_dir}/{f}')
```

## 坑 2: delete_annot + saveIncr 后残留 underline

**症状**: 跑过 highlight 后, 想 reset, 用 `page.delete_annot(a)` + `doc.saveIncr()`. 再 reopen `len(annots)` 还是 > 0. underline 还在.

**根因**: PyMuPDF `delete_annot` 不总是生效 (native 行为有 bug), saveIncr 只追加不删除.

**修法**: 完全不依赖 delete_annot. 直接**重置 step4 目录 (rmtree + 从 step3 复制干净 PDF)**, 不要试图删 underline. 这是最稳的 reset 模式.

```python
import shutil
pn_dir = f'{STEP4}/P3-1'
if os.path.exists(pn_dir):
    shutil.rmtree(pn_dir)
shutil.copytree(f'{STEP3}/P3-1', pn_dir)  # 干净 PDF, 0 underline
```

**验证**: 用 PDF 字节 grep `/Type/Annot/Subtype/Underline/` 数真 underline. 比 `len(annots)` 可靠, 也避开 `a.type` segfault.

```python
import re
with open(pdf, 'rb') as f:
    data = f.read()
matches = re.findall(rb'/Type/Annot/Subtype/Underline/.*?Rect\[([\d. ]+)\]', data)
print(f'PDF underline 数: {len(matches)}')
for m in matches:
    nums = [float(x) for x in m.split()]
    print(f'  Rect pt: ({nums[0]:.0f}, {nums[1]:.0f}) - ({nums[2]:.0f}, {nums[3]:.0f})')
```

## 坑 3: PyMuPDF y 坐标翻转

**症状**: 给 `Rect(10, 10, 200, 20)` (想画在 page 顶) → PDF 字节 grep 显示 Rect(10, 1466, 200, 1476) (实际在 page 底, 假设 page height=1486).

**根因**: PyMuPDF 接受 y-down 坐标 (顶=0), 但 PDF 内部存 y-up (底=0). PyMuPDF 自动翻转. 这跟 `get_text("blocks")` 返回的 y 不一样 (blocks 返回 y-down, page rect 也是 y-down).

**修法**: 知道这个陷阱后, **只关心 PDF 字节里的最终坐标**, 不要试图"画在 y=10 = 顶"还是"画在 y=1466 = 底". **验证一次再继续**.

```python
# 给 PyMuPDF Rect (y-down)
rect = fitz.Rect(54, 1116, 420, 1140)  # 假设 PDF height=1486
# 验证 PDF 内部存 (y-up)
# y_up = 1486 - y_down
# Rect 实际存 Rect(54, 1486-1140, 420, 1486-1116) = Rect(54, 346, 420, 370)
# 这跟 jpg y 对应: jpg y_down = (1486 - y_up) / 1486 * jpg_height
```

## 坑 4: 共享 _pdf_jpg/ 目录跨 Pn-x

**症状**: 多 Pn-x 跑算法, 共用一个 `_pdf_jpg/` 目录. A.pdf 的 jpg 跟 B.pdf 的 jpg 混, 找不到正确页.

**根因**: _pdf_jpg/ 没归到 Pn-x 目录下, 是临时共享.

**修法**: 每个 Pn-x 独立 `pn_dir/_pdf_jpg/`, 不跨 Pn-x.

```python
# 每个 Pn-x 独立
jpg_dir = f'{STEP4}/{pn_key}/_pdf_jpg'
if os.path.exists(jpg_dir):
    shutil.rmtree(jpg_dir)
os.makedirs(jpg_dir)
```

## 算法驱动 + 步骤拆开 (FIRST-CLASS 用户硬规则)

用户原话 (2026-08-05):

> "你肯定要把每个不同的步骤拆开, 算法驱动来调度步骤和工具, 确保工作正确啊, 这是我的思路. 你要怎么设计, 你要根据自己的具体情况去设计稿解决方案, 才能确保完美复现."

**核心要求**:
1. **每个步骤独立函数** — 一行能跑, 不嵌套不黑盒
2. **步骤间只传数据, 不传 state** — 每次跑新算法, 不依赖上一次 state
3. **主函数一键复现** — `def run_pnx(pn_key) -> dict`, 一行调用能跑通整个算法
4. **每步输出可验证** — print 中间结果, 写中间文件 (jpg, JSON), 跑完能 audit
5. **跑前 reset** — 不能依赖"上次的 underline 还在", 每次 rm + copy
6. **跑完自检** — vision_analyze 看 PNG OR PIL+numpy 找浅黄像素, 不让 user 确认

## P3-2 完整复现 recipe (v2.15 终极版)

```python
import os, shutil, fitz, csv
from PIL import Image, ImageDraw
import numpy as np

ROOT = '/Users/david/Desktop/雷管方案_文献整理'
STEP3 = f'{ROOT}/step3_pdf下载_160目录'
STEP4 = f'{ROOT}/step4_highlight_96目录_合并DOI'
TRUTH = f'{ROOT}/step2_标注分析/_citation_table/citation_table.csv'

# B 选项中黄: RGB(255, 230, 100), 4px
RGB_JPG = (255, 230, 100)
RGB_PDF = (1.0, 230/255, 100/255)
DPI = 120

def reset_pnx(pn_key):
    """步骤 1: 重置 (rmtree + 复制干净)"""
    pn_dir = f'{STEP4}/{pn_key}'
    if os.path.exists(pn_dir):
        shutil.rmtree(pn_dir)
    shutil.copytree(f'{STEP3}/{pn_key}', pn_dir)

def get_truth(pn_key):
    """步骤 2: 读真值"""
    slide = str(int(pn_key.split('-')[0].lstrip('P')))
    num = str(int(pn_key.split('-')[1]))
    with open(TRUTH) as f:
        for r in csv.DictReader(f):
            if r['﻿PPT页'] == slide and r['第几条'] == num:
                return r['引用语义（上下文）'], r['PPT中的文献引用 完整字段']
    return None, None

def select_main_pdf(pn_dir, pn_key):
    """步骤 3: 显式选 main PDF (避开 fallback)"""
    pdfs = [f for f in os.listdir(pn_dir) if f.startswith(f'{pn_key}_main') and f.endswith('.pdf')]
    if not pdfs:
        pdfs = [f for f in os.listdir(pn_dir) if f.endswith('.pdf') and not f.startswith('_v39')]
    return f'{pn_dir}/{pdfs[0]}' if pdfs else None

def render_jpg(pdf_path, out_dir, max_pages=20):
    """步骤 4: PDF 每页导 jpg (dpi=120)"""
    os.makedirs(out_dir, exist_ok=True)
    doc = fitz.open(pdf_path)
    paths = []
    for i in range(min(max_pages, len(doc))):
        pix = doc[i].get_pixmap(dpi=DPI)
        out = f'{out_dir}/page_{i+1:03d}.jpg'
        pix.save(out)
        paths.append(out)
    doc.close()
    return paths

def find_proof_blocks(pdf_path, page_num, y_range):
    """步骤 5: PyMuPDF get_text("blocks") 提应证段 (真实 PDF pt 坐标)"""
    doc = fitz.open(pdf_path)
    blocks = doc[page_num].get_text("blocks")
    proof = []
    for b in blocks:
        x0, y0, x1, y1, text = b[0], b[1], b[2], b[3], b[4].strip()
        if y_range[0] < y0 < y_range[1] and y_range[0] < y1 < y_range[1]:
            proof.append((x0, y0, x1, y1, text))
    doc.close()
    return proof

def highlight_multi_lines(pn_key, blocks, page_num):
    """步骤 6: 多行画浅黄细线 (jpg + PDF underline)"""
    pn_dir = f'{STEP4}/{pn_key}'
    pdf_path = select_main_pdf(pn_dir, pn_key)
    jpg_path = f'{pn_dir}/_pdf_jpg/page_{page_num+1:03d}.jpg'

    # jpg 上画
    img = Image.open(jpg_path).convert('RGB')
    draw = ImageDraw.Draw(img)
    for x0, y0, x1, y1, _ in blocks:
        jx0 = x0 * DPI / 72
        jy1 = y1 * DPI / 72
        jx1 = x1 * DPI / 72
        draw.line([(jx0, jy1), (jx1, jy1)], fill=RGB_JPG, width=4)
    img.save(f'{pn_dir}/page_{page_num+1:03d}_highlighted.jpg')

    # PDF underline
    doc = fitz.open(pdf_path)
    page = doc[page_num]
    for x0, y0, x1, y1, _ in blocks:
        rect = fitz.Rect(x0, y0, x1, y1)
        annot = page.add_underline_annot(rect)
        annot.set_colors(stroke=RGB_PDF)
        annot.update()
    try:
        doc.saveIncr()
    except:
        tmp = pdf_path + '.tmp'
        doc.save(tmp, garbage=4, deflate=True)
        doc.close()
        shutil.move(tmp, pdf_path)
        return
    doc.close()

def verify_pdf_underline(pdf_path):
    """步骤 7: 验证 PDF underline (PDF 字节 grep, 避开 a.type segfault)"""
    import re
    with open(pdf_path, 'rb') as f:
        data = f.read()
    matches = re.findall(rb'/Type/Annot/Subtype/Underline/.*?Rect\[([\d. ]+)\]', data)
    print(f'PDF underline 数: {len(matches)}')
    for m in matches:
        nums = [float(x) for x in m.split()]
        print(f'  Rect pt: ({nums[0]:.0f}, {nums[1]:.0f}) - ({nums[2]:.0f}, {nums[3]:.0f})')
    return len(matches)

def verify_jpg_clusters(jpg_path, expected_n):
    """步骤 7b: 验证 jpg 中黄线 cluster 数"""
    img = Image.open(jpg_path).convert('RGB')
    arr = np.array(img)
    yellow_mask = (
        (arr[:, :, 0] >= 245) &
        (arr[:, :, 1] >= 215) & (arr[:, :, 1] <= 245) &
        (arr[:, :, 2] >= 80) & (arr[:, :, 2] <= 115)
    )
    yellow_rows = np.where(yellow_mask.any(axis=1))[0]
    clusters = []
    prev_y = -10
    start = None
    for y in yellow_rows:
        if y - prev_y > 5:
            if start is not None:
                clusters.append((start, prev_y))
            start = y
        prev_y = y
    if start is not None:
        clusters.append((start, prev_y))
    print(f'jpg 中黄线 cluster 数: {len(clusters)} (期望 {expected_n})')
    return len(clusters) == expected_n

def run_pnx(pn_key, page_num, y_range):
    """一键复现主函数 (P3-2 page 3, y 60-170)"""
    print(f'\\n=== {pn_key} 一键复现 ===')

    # 1. 重置
    reset_pnx(pn_key)

    # 2. 读真值
    truth_d, truth_c = get_truth(pn_key)
    print(f'真值 D: {truth_d[:100]}...')

    # 3. 选 main PDF
    pn_dir = f'{STEP4}/{pn_key}'
    pdf_path = select_main_pdf(pn_dir, pn_key)
    print(f'PDF: {os.path.basename(pdf_path)}')

    # 4. 渲染 jpg
    jpg_dir = f'{pn_dir}/_pdf_jpg'
    render_jpg(pdf_path, jpg_dir)
    print(f'渲染 jpg: {len(os.listdir(jpg_dir))} 页')

    # 5. 提应证段
    blocks = find_proof_blocks(pdf_path, page_num, y_range)
    print(f'应证段: {len(blocks)} 行')

    # 6. 画浅黄细线
    highlight_multi_lines(pn_key, blocks, page_num)

    # 7. 验证
    n_pdf = verify_pdf_underline(pdf_path)
    jpg_path = f'{pn_dir}/page_{page_num+1:03d}_highlighted.jpg'
    ok_jpg = verify_jpg_clusters(jpg_path, len(blocks))

    print(f'\\n=== 结果: PDF underline={n_pdf}, jpg cluster OK={ok_jpg} ===')
    return n_pdf == len(blocks) and ok_jpg

# === 跑 P3-2 ===
if __name__ == '__main__':
    run_pnx('P3-2', page_num=2, y_range=(60, 170))
    # 期望输出:
    # === P3-2 一键复现 ===
    # 真值 D: PPT标号2: 出现在 1 个位置 (右半区域主标题)...
    # PDF: P3-2_main_健康中国行动_癌症防治行动实施方案2023-2030年_Journal_2023.pdf
    # 渲染 jpg: 11 页
    # 应证段: 4 行
    # PDF underline 数: 4
    # jpg 中黄线 cluster 数: 4 (期望 4)
    # === 结果: PDF underline=4, jpg cluster OK=True ===
```
