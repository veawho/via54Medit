## PowerPoint 渲染铁律

- macOS Keynote 跟 PowerPoint 视觉不一致
- LibreOffice 也视觉不一致
- **必须用 PowerPoint AppleScript 渲染**, 不做 fallback

`export_ppt_to_images.py`:
```python
# 强制只走 PowerPoint
files, err = export_via_powerpoint(args.pptx, args.out_dir, args.dpi)
if err:
    print(f'❌ PowerPoint 渲染失败: {err}')
    print('  (Keynote/LibreOffice 视觉不一致, 不 fallback)')
    sys.exit(1)
```

## 12 列 CSV 格式 (A-L)

```
A_slide          # slide 序号
B_mark           # slide 引用序号
C_citation       # 引用文献完整字段
D_visual_text_analysis  # 视觉+文字分析 (XML 位置 + 文字 + 真值 D)
E_DOI            # DOI (带超链接)
F_download_url   # 来源链接 → 阅读全文
G_pdf_status     # ✅ N PDF / ❌ 无 PDF
H_highlight_status     # ✅ N 文件 / ❌ 待做

J_align_C_PDF    # 引文 ↔ C+E ↔ 下载 PDF ↔ HL PDF

```
