## 根因 #1: 没扫系统工具

我之前看 `which soffice` / `which libreoffice` → 都没装 → 立刻说"要装 LibreOffice"。

**完全没扫** `/Applications/` 里已有的:
- `Keynote Creator Studio.app` (bundle id `com.apple.Keynote`)
- `Microsoft PowerPoint.app` (bundle id `com.microsoft.Powerpoint`)
- `Pages Creator Studio.app`

**正确做法**: 写任何 "需要 X 工具" 之前, **先扫** `/Applications/` + `mdfind` + `which`, 不在再问用户。

扫描模式 (debug 后发现):
```bash
# 1. 列 /Applications
ls /Applications/ | grep -iE "keynote|office|powerpoint|pages"

# 2. mdfind 拿所有相关
mdfind -name "keynote" 2>/dev/null | head -5
mdfind -name "powerpoint" 2>/dev/null | head -5

# 3. 查 bundle id
defaults read "/Applications/Keynote Creator Studio.app/Contents/Info.plist" CFBundleIdentifier

# 4. AppleScript 类名 (空格要替换)
osascript -e 'tell application "Keynote" to get version'
# OK → 用 "Keynote" 不是 "Keynote Creator Studio.app"
```

## 根因 #3: AppleScript `tell` 块拆分丢状态

我之前误把 AppleScript 拆成多次 `tell` 调用:

```python
# ❌ 错 — 拆 2 次 tell, 中间 sleep 6 seconds 后 state 丢失
ascript1 = 'tell application "Keynote" to open POSIX file "..."'
subprocess.run(['osascript', '-e', ascript1])
time.sleep(6)
ascript2 = 'tell application "Keynote" to export front document to ... as PDF'
subprocess.run(['osascript', '-e', ascript2])
# → rc=1, error -609 "连接无效"
```

**正确做法**: 1 个 `tell` 块全包:

```python
# ✅ 对 — 1 个 tell 块, 内部用 set theDoc 抓 front document
ascript = '''
tell application "Keynote"
    open POSIX file "<abs_path>"
    delay 6
    set theDoc to front document
    export theDoc to POSIX file "<pdf_path>" as PDF
    delay 2
    close theDoc saving no
end tell
'''
subprocess.run(['osascript', '-e', ascript], timeout=90)
```

实测 43 页 PPT → 21MB PDF → 43 张 JPG, **rc=0**。

## 完整可工作的 PPT→图片 pipeline (v1.9.0)

```python
def export_ppt_via_keynote(pptx_path, out_dir, dpi=120):
    """Keynote AppleScript → PDF → pdftoppm → jpg"""
    os.makedirs(out_dir, exist_ok=True)
    pdf_path = os.path.join(out_dir, '_tmp.pdf')
    # 清旧 jpg
    for f in os.listdir(out_dir):
        if f.endswith('.jpg'):
            os.remove(os.path.join(out_dir, f))

    abs_pptx = os.path.abspath(pptx_path)
    # 1 个 tell 块, set theDoc 抓
    ascript = f'''
tell application "Keynote"
    open POSIX file "{abs_pptx}"
    delay 6
    set theDoc to front document
    export theDoc to POSIX file "{pdf_path}" as PDF
    delay 2
    close theDoc saving no
end tell
'''
    r = subprocess.run(['osascript', '-e', ascript], capture_output=True, text=True, timeout=90)
    if r.returncode != 0 or not os.path.exists(pdf_path):
        return None, f'Keynote failed: {r.stderr[:200]}'

    # pdftoppm 转图
    subprocess.run(['pdftoppm', '-jpeg', '-r', str(dpi), pdf_path,
                    os.path.join(out_dir, 'slide')], capture_output=True, timeout=120)
    # 重命名 slide-1.jpg → slide_001.jpg
    for f in os.listdir(out_dir):
        if f.startswith('slide-') and f.endswith('.jpg'):
            n = int(f.split('-')[-1].split('.')[0])
            os.rename(os.path.join(out_dir, f), os.path.join(out_dir, f'slide_{n:03d}.jpg'))
    # 删中间 PDF
    os.remove(pdf_path)
    return sorted(os.listdir(out_dir)), None
```

`export_ppt_to_images.py` 已用这套机制替换 LibreOffice 路径, 默认输出 `<project_root>/_ppt_renders/`.
