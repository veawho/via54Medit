## 子 agent vision 配对 SOP

### 1. 准备 slide_marks.json

```python
import json
from pptx import Presentation

PPT = '/Users/david/Desktop/雷管方案_文献整理/PPT原版_雷管方案_三重获益_引领uHCC一线治疗_0622.pptx'
EMU = 914400
prs = Presentation(PPT)

def find_marks(slide):
    marks = []
    for shape in slide.shapes:
        if not shape.has_text_frame: continue
        for para in shape.text_frame.paragraphs:
            line = para.text
            if not line: continue
            m = re.search(r'([1-9][0-9]?)\s*$', line)
            if m:
                n = int(m.group(1))
                if 1 <= n <= 18:
                    marks.append({'n': n, 'context': line[:80], 'shape': shape.name})
    return marks

def find_cites(slide):
    cites = []
    for shape in slide.shapes:
        if not shape.has_text_frame or not (shape.top and shape.height): continue
        if shape.top/EMU < 6.0: continue
        if shape.name.startswith('矩形') or '页脚占位符' in shape.name: continue
        for line in shape.text_frame.text.split('\n'):
            line = line.strip()
            if not line or line.startswith('*'): continue
            cites.append(line)
    return cites

all_slides = []
for slide_idx, slide in enumerate(prs.slides, 1):
    all_slides.append({
        'slide': slide_idx,
        'marks': find_marks(slide),
        'cites': find_cites(slide),
        'img': f'/Users/david/Desktop/雷管方案_文献整理/_ppt_renders/slide_{slide_idx:03d}.jpg'
    })

with open('/tmp/slide_marks.json', 'w') as f:
    json.dump(all_slides, f, ensure_ascii=False, indent=2)
```

### 3. 子 agent prompt 必含 3 规则

1. **1,2 共享**: mark_1 和 mark_2 填**同一引用** (来自同一 cell)
2. **整页标号 1**: 页脚 "1. xxx" 标号 1 涵盖整页
3. **多标号区间 1-3**: 1, 2, 3 三个独立标号都填同一引用 (取区间首条 cite)

### 4. 输出格式

```json
{
  "3": {"1": "引用内容", "2": "引用内容", "3": "no_match", "4": "..."},
  "4": {"1": "引用内容", ...},
  ...
}
```

### 5. 合并 + 对照真值算准确率

```python
import json, csv, re

vision = {}
for f in ['/tmp/p3_p10_vision.json', '/tmp/p11_p19_vision.json',
          '/tmp/p20_p28_vision.json', '/tmp/p29_p36_vision.json',
          '/tmp/p37_p43_vision.json']:
    vision.update(json.load(open(f)))

with open('/Users/david/Desktop/雷管方案_文献整理/_citation_table/citation_table.csv') as f:
    truth = list(csv.DictReader(f))

truth_map = {(int(r['﻿PPT页']), int(r['第几条'])): r['PPT中的文献引用 完整字段'].strip() for r in truth}

def norm(s):
    return re.sub(r'\s+', '', s.lower())[:25] if s else ''

correct = 0; wrong = 0; miss = 0
for (s, n), truth_c in truth_map.items():
    s_str = str(s)
    if s_str not in vision:
        miss += 1; continue
    my_c = vision[s_str].get(str(n), '')
    if not my_c or my_c == 'no_match':
        miss += 1
    elif norm(my_c) == norm(truth_c):
        correct += 1
    else:
        wrong += 1

print(f'配对准确率: {correct/(correct+wrong)*100:.1f}%')
print(f'总体命中率: {correct/len(truth_map)*100:.1f}%')
print(f'对: {correct}, 错: {wrong}, 漏: {miss}')
```

## 已知 caveat

- 每个子 agent 漏看 5-30 个标号 (重点是表格里的上标)
- P5 14 行表格, 子 agent 只识别 banner 标号 1, 漏了 17 个表格内标号
- 解决: 让 agent 先生成"应配对列表" (含标号 + 位置), 再挑该填的引用
