# v2.9.0 Pydantic schema + Voting + 4 类幻觉过滤

**版本**: v2.9.0 (2026-08-05)
**目标**: 把 vision_analyze 跑出来的 `data_points` (不稳定) 用 Pydantic schema 强制 + 取并集 majority + 4 类幻觉过滤砍掉幻觉, 保留真值.

## 为什么需要 Pydantic

之前 v6-v7 直接信 vision 提的 `data_points`, 跑两次结果差 40% 一致率. vision_analyze 是 LLM, 本质随机 (temperature 不为 0 时). Pydantic 强制 schema 不能解决内容正确, 但能:
- 挡 mark=0 / 负数 (Field ge=1)
- 挡超过 20 个 data_points (schema validator, 防止幻觉过载)
- 强制 label 长度 1-200, 防止空 label 或 500 字长文
- 强制 unit 长度 0-20
- 后续每字段 validator 可加

## 为什么 voting 比 union 好

**N=3 union**: 100% 召回, 但保留幻觉 (P31 35.5/35.8 两个都留)
**N=3 majority + median**: 砍掉单次幻觉, 保留 ≥2 次出现的值, 数值取 median (35.5/35.8/35.8 → 35.8)

**实施**: 真要 N=3, 跑 3 次 vision_analyze, 各自走 Pydantic 校验, 再 vote_slide(runs) 合并.

**现实**: vision_analyze 单次已经要 ~30s, N=3 每次 = 90s × 43 slide = 64 分钟. 用 subagent 并行 4 批 (P3-P12 / P13-P22 / P23-P30 / P31-P43) 1 轮 7 分钟. 但稳定性只 40% 一致, N=3 投票理论上能拉高到 70-80%, 仍然有 20% 幻觉.

**彻底解决方案**: 上 MLX-VLM (本地 VLM + JSON Schema constrained decoding) 或云端 instructor 强制 Pydantic (跨 3 次都是结构化输出, 投票有效).

## 4 类幻觉过滤 (HALLUCINATION_GUARD)

```python
HALLUCINATION_GUARD = {
    "min_decimals_other_source": 2,   # XML 是 35.8 (2位), vision 给 35 (1位) → 降级
    "soft_max_pct": 80.0,             # oncology KPI 几乎不 >80% (除了 36mo OS) → 砍
    "max_dup_per_slide": 2,           # 同一 (label,value) 在 1 张 slide 出现 >2 → 共享引文,留 1 次
    "unit_mismatch_block": True,      # 同 label 在 XML unit="%" 但 vision 给 unit="mo" → drop vision
}
```

### 4 类幻觉类型表

| 模式 | 触发条件 | 处理 | 案例验证 |
|---|---|---|---|
| 精度降级 | XML 35.8 vs vision 35.5 | 警告 + XML wins | P31 ✅ |
| CI 误读 | value ≥ 80% (CI 边界 95/100) | drop | — |
| 共享引文 dupe | 同 (label,value) >2 次 | 留 1 次 | P31 ✅ |
| 单位错位 | label "OS" 但 unit="mo" (duration 不是 rate) | drop vision | 已观察 |
| 总量幻觉 | slide DP 数 > 20 | schema 拒 | SlideVision validator |
| 超出 mark 范围 | mark > 实际 slide 数 | schema `ge` 拒 | pydantic 自动 |

## 关键设计

- **XML 优先** (引文, 位置 100% 稳定)
- **Vision 补充** (chart/table data_points, 96.9% 命中)
- **冲突时 XML 胜** (vision 偶尔会提供跟 XML 一致的 citation label e.g. 期刊缩写, update 会覆盖 XML 精确版)
- **不要用 dict.update**, 用 whitelist 模式 + dedupe

## 阈值校准注意

86.2% XML 命中 + 14% 真值没匹配说明 14% 真实噪声 (引文没在 PPTX shape 找到). 别把幻觉过滤阈值设过紧, 否则会丢真值. 建议 P0 上线时所有 drop 写日志, 50 个 drop 后统计精校阈值.
