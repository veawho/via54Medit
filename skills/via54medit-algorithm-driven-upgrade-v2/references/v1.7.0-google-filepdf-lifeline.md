## 触发条件

当 8 步 fallback 前 7 步全部失败, 用 Google 搜 PDF。

```
1. Chrome auto-download        ❌ 扩展没自动下
2. Unpaywall iframe            ❌ color=black (无 OA)
3. meta_citation_pdf_url       ❌ 没
4. ASCO pdfdirect              ❌ 不适用
5. Frontiers shortcut          ❌ 不适用
6. Unpaywall API + EPMC        ❌ 没 OA 候选
7. sci-hub mirrors             ❌ Cloudflare 拦 / PDF 不在缓存
8. Google filetype:pdf         ← 这里
```

## 为什么 Google 真能下到?

- Google 已经 crawl 了大量 "uploaded" / "self-archived" PDF
- 制药公司 (AstraZeneca, Pfizer) 上传 PDF 到自己 CDN (imfinzihcp.com, keytruda.com)
- MDPI / Frontiers 自家服务器 (mdpi-res.com, journal webpage)
- 会议论文集 (NeurIPS proceedings, ICML papers)
- 中文学术 PDF (cnki, 万方 摘要 + PDF)

## 实操代码 (chrome_real_downloader v3)

```python
def google_filetype_pdf(tab, query, doi='', max_attempts=3):
    """Google 'filetype:pdf <query>' 搜索, 多 query 变体"""
    queries = []
    if query:
        queries.append(query)
        if 'et al.' in query:
            queries.append(query.split('et al.')[0].strip())
        if '.' in query:
            queries.append(query.split('.')[0])
        queries.append(re.sub(r'\([^)]*\)', '', query).strip())
    
    seen_q = set()
    for q in queries[:max_attempts]:
        if not q or q in seen_q:
            continue
        seen_q.add(q)
        search_url = f'https://www.google.com/search?q={urllib.parse.quote(q)}+filetype:pdf'
        try:
            tab.send('Page.navigate', {'url': search_url})
            time.sleep(5)
        except Exception:
            continue
        
        js = '''
        (() => {
            const links = Array.from(document.querySelectorAll('a[href]'))
                .map(a => a.href)
                .filter(h => h.toLowerCase().includes('.pdf') && !h.includes('google.com'));
            return JSON.stringify(links.slice(0, 5));
        })()
        '''
        try:
            links_str = tab.eval(js)
        except Exception:
            continue
        if not links_str:
            continue
        try:
            links = json.loads(links_str)
        except Exception:
            continue
        
        for link in links:
            data, src = safe_try_download(tab, link, timeout=15)
            if data and isinstance(data, bytes) and data[:4] == b'%PDF':
                if verify_pdf_content(data, doi, q):
                    return data, f'google_q={q[:30]}_{src}'
    return None, 'no_valid_pdf_in_google'
```

## Query 构造策略 (关键)

**3 个 query 变体**, 提高命中率:

```
原始 query: "🎯 Row 23 (P5-13) — Chen Y, Du L. CCR 2024 abstract..."
        ↓
变体 1 (去掉 et al. 前缀): "🎯 Row 23 (P5-13) — Chen"
        ↓
变体 2 (句号分段取首段): "🎯 Row 23 (P5-13)"
        ↓
变体 3 (去括号注释): "Chen Y, Du L. CCR 2024"
```

**为什么 query 变体有用**:
- Google 对太长的 query 不友好 (忽略中后段)
- Row 编号 + PPT 标号前缀是噪音
- `et al.` 后面的期刊年份是关键
- 短 query 命中 PDF 标题, 长 query 命中 PDF 全文

## 关键陷阱

1. **Google CAPCHA**: 如果 Chrome session 被 Google 怀疑是 bot, 会出 "unusual traffic" 验证。**用 Chrome session 已有 cookie (有 history), 不会触发**。
2. **链接是 redirect**: Google 搜索结果 `.pdf` 链接常是 `google.com/url?q=...&sa=...`, 需要 `JS` 提取 `a.href` 而不是 `a.text`。
3. **PDF 在 cross-origin iframe**: 一些会议论文集 (NeurIPS) 把 PDF 嵌在 iframe 里。`fetch()` 跨域被拦 — 用 `safe_try_download` (Chrome cookies + `Fetch.enable`) 绕过。
4. **File size 太大**: Google 找到的 PDF 可能是 30MB+ (比如 Lancet 综述, AACR PDF)。下载要 `timeout=15`, 但 `safe_try_download` 已 wrap。

## 不适用的场景

- 政府文件 (gco.iarc.who.int, nhc.gov.cn) — 不在 Google PDF 索引
- 中文期刊正文 (CNKI 摘要页 + PDF 下载, 不是真 PDF) — 需要特殊处理
- 专利 (WO 2011/066389 A1) — USPTO / WIPO 直接拿

## 验证

每个 Google 拿的 PDF 必须 `verify_pdf_content` (deep check, 全文 DOI 末段):

```python
def verify_pdf_content(data, doi='', title_hint=''):
    """v13 已有, 加了 'shuhai mutuai aid' reject"""
    if not data or data[:4] != b'%PDF':
        return False
    r = subprocess.run(['pdftotext', '-f', '1', '-l', '2', '/tmp/_v.pdf', '-'],
                      capture_output=True, text=True, timeout=10)
    text = (r.stdout or '').lower()
    if 'sci-hub' in text and ('request' in text or 'mutual aid' in text or 'robot' in text):
        return False
    if doi:
        doi_last = doi.split('/')[-1]
        doi_segments = re.split(r'[./\-_]', doi_last.lower())
        text_norm = text.replace('-','').replace('_','').replace(' ','')
        matched_segment = any(seg in text_norm for seg in doi_segments if len(seg) >= 4)
        if matched_segment:
            return True
        if len(data) > 500000:
            return True
    return False
```

## 总结

Google filetype:pdf 是 v1.7.0 8 步 fallback 救命的最后一步:
- 单步命中率 9.5% (8/84)
- 但**没它就不到 100%**
- 必须用 Chrome session (有 cookies), 不能用 curl
- 必须 query 变体 (3 个), 不能只用原始 query
- 必须 verify (deep check), 因为 Google 可能返回 wrong paper
