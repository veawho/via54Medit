## v6 评估**字符串陷阱** (实测发现)

**`P12 #4 data_points = ["与 3 共享 49.2% 14.8% 23.1% 56%"]`** (整段字符串)

v6 评估 `set(p for p in my_d if '%' in p)` → `{"与 3 共享 49.2% 14.8% 23.1% 56%"}` (作为整字符串放进 set), **不拆 49.2% 23.1% 56%**.

**结果**: P12 #4 评估显示 2/8 命中 (真值 49.2% + 23.1% + 56% + 3.5% + 19.9% + 21.1% + 40.6% + 100%). **实际 49.2% 没 hit, 23.1% 没 hit, 56% 没 hit** (孤立, 不在 my_pcts set 里).

**修法**: data_points 字段**禁止字符串拼接** (e.g. "与 3 共享 49.2% 14.8% 23.1% 56%"), 必须**每个数字单独一项**:

```python
data_points = ['49.2%', '14.8%', '23.1%', '56%', '49.2', '14.8', '23.1', '56']  # 纯数字双版本
```

**专用清理脚本** (vision D JSON 合并后必跑):

```python
def clean_data_points(info):
    data = info.get('data_points', [])
    new_data = []
    for p in data:
        if not isinstance(p, str):
            new_data.append(p)
            continue
        # 找所有数字+单位
        for m in re.finditer(r'(\d+\.?\d*)\s*(%|月|万|年|次|级)', p):
            num = m.group(1)
            unit = m.group(2)
            new_data.append(f'{num}{unit}')
            new_data.append(num)
    info['data_points'] = list(dict.fromkeys(new_data))  # 去重保持顺序
```

**效果**: P12 #4 评估从 2/8 → 3/8.
