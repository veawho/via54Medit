## 5 仓库具体评估

### 1. scanny/python-pptx
- URL: https://github.com/scanny/python-pptx
- **核心能力**: 解析 PPTX 内部 XML (slide/shape/text/table/coordinate)
- **稳定性**: 100% (XML 确定性读取)
- **本机**: pip install python-pptx (已装 1.0.2)
- **用法**: `from pptx import Presentation; prs = Presentation(path); slide.shapes`
- **本项目落地**: v7 双轨轨道 A, 86.2% 命中真值 C 字段

### 2. googleapis/python-genai (新, 旧 google-gemini/generative-ai-python 已弃用)
- **核心能力**: Gemini API + JSON Schema / Pydantic 强制输出
- **新库**: `pip install google-genai`
- **关键**: `response_mime_type='application/json'` + `response_json_schema`
- **本项目**: 用 Pydantic 生成 schema + Gemini 跑视觉

### 3. anthropics/anthropic-sdk-python
- **核心能力**: Claude API + 图片 + structured output
- **示例**: `examples/images.py` + `examples/structured_outputs.py`
- **本项目**: 备用视觉 provider

### 4. openai/openai-python
- **核心能力**: OpenAI API + Pydantic parsing
- **示例**: `examples/parsing.py` + `examples/parsing_tools.py`
- **本项目**: 备用视觉 provider

### 5. Blaizzy/mlx-vlm (Mac Apple Silicon)

## 关键发现

### ✅ python-pptx 是必须采用 (100% 稳定)
XML 确定性读取, 跨 1000 次跑结果一致. vision 不可能是 100% 稳定.

### ⚠️ OptiLLM 投票是减噪手段, 不是稳定性保证
N=3 majority + median 砍 1 次 hallucination, 但 N=5 浪费 67% token.
JSON Schema 强制输出形状, 不能保证视觉事实正确.

### ❌ 任何 prompt 约束都不可靠
同等 prompt 同图跑 2 次 → 39.6% 一致率. 必须双轨 (XML 主干 + Vision 验证).

```python
# 2. Pydantic schema 强制 vision 输出
from pydantic import BaseModel, Field, field_validator

class ChartDataPoint(BaseModel):
    label: str = Field(min_length=1, max_length=200)
    value: float
    unit: str = Field(default="", max_length=20)

class SlideVision(BaseModel):
    slide_mark: int = Field(ge=1)
    data_points: list[ChartDataPoint] = Field(default_factory=list)
    
    @field_validator("data_points")
    @classmethod
    def _cap_dp(cls, v):
        if len(v) > 20:
            raise ValueError("hallucination")
        return v

# 3. N=3 majority + median value
from collections import Counter
import statistics

def vote_slide(runs: list[SlideVision]) -> SlideVision:
    canonical_mark = Counter(r.slide_mark for r in runs).most_common(1)[0][0]
    dp_buckets = defaultdict(list)
    for r in runs:
        for dp in r.data_points:
            key = (dp.label.strip().lower(), round(dp.value, 4))
            dp_buckets[key].append(dp)
    canonical = []
    for (label, _rval), bucket in dp_buckets.items():
        if len(bucket) >= (len(runs) // 2 + 1):
            canonical.append(ChartDataPoint(
                label=bucket[0].label,
                value=statistics.median(d.value for d in bucket),
                unit=Counter(d.unit for d in bucket).most_common(1)[0][0],
            ))
    return SlideVision(slide_mark=canonical_mark, data_points=canonical)
```
