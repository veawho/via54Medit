## PNG 压缩后 RGB 不精确 (自检陷阱)

**PNG 保存后 RGB 不再精确**:
- 输入 `(255, 230, 100)`
- 保存 PNG 后像素可能变成 `(255, 230, 100)` 或 `(254, 232, 102)` (压缩变化)
- 严格匹配 `==` 会 0 命中
- **必须用宽范围检测**:
  - R: 240-255
  - G: 215-245
  - B: 80-115

**正确**:
```python
yellow_mask = (arr[:, :, 0] >= 240) &
               (arr[:, :, 1] >= 215) & (arr[:, :, 1] <= 245) &
               (arr[:, :, 2] >= 80) & (arr[:, :, 2] <= 115)
```

**错误** (会 0 命中):
```python
yellow_mask = (arr[:, :, 0] == 255) &
               (arr[:, :, 1] == 230) &
               (arr[:, :, 2] == 100)
```

**用户发的 P3-1 PDF**:

- 这才是真应证 PPT 视觉 "中国肝癌新发和死亡病例占全球近半数"

**step3 P3-1 main PDF**:
- `GLOBOCAN_2022_Liver_IARC.pdf` (2 页) — 洲级数据 (Asia 70.2% 等), **没有 China 单独数据**

**修法** (关键):
- step3 多 PDF 时, **必须用真值 PDF** (用户发的, 含 PPT 视觉对应的概念)
- 不是 main 就是对的 — 看真值 D 字段要什么概念, 找对应 PDF
- 把用户发的 PDF 复制到 step4: `cp doc_xxx_P3-1.pdf step4/P3-1/P3-1_globocan_summary.pdf`
- 然后跑视觉配对

**算法设计原则**:
1. **真值优先** (用户原话: "我已经发给你了") — 用用户发的 PDF, 不是 main PDF
2. **main PDF 是 fallback** — 当用户没发时, 用 main + IARC 等
3. **vision 看真值 PDF jpg** — 找 "中国占全球 24.2%" 应证段, 不是 "Asia 70.2%"
