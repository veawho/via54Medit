## 1. 图表/表格 vs 段落 — 不同 highlight 类型

**用户原话**: "P3-1, 既然是图表, 那么标注就应该用黄线把整个对应的图表框起来"

**两种 highlight annot**:
- **段落/整句**: `page.add_underline_annot(rect)` (type 9, **文字下方细线**)
- **图表/表格**: `page.add_rect_annot(rect)` (Square annot, **矩形框整个图表**)

```python
# 段落 (文字下细线)
annot = page.add_underline_annot(rect)
annot.set_colors(stroke=(1.0, 0.8, 0.0))
annot.update()

# 图表/表格 (矩形框)
annot = page.add_rect_annot(rect)
annot.set_colors(stroke=(1.0, 0.8, 0.0))
annot.update()
```

**实战案例 (2026-08-05)**:
| 标号 | 类型 | 应证 | annot |
|------|------|------|-------|
| P3-1 | 图表 (Asia 区域行) | "Asia 70.2% 591,519 cases" | Square |
| P3-2 | 段落 | "(二)主要目标...46.6%, 患者疾病负担..." 4 行 | Underline ×4 |
| P3-3 | 图表 (Fig. 2) | "Age-standardized 5-year relative survival" 柱图 | Square |
| P3-4 | 图表 (Fig. 1 + Table 2 BCLC) | BCLC A/B/C/D 4 行 + 生存曲线 | Square |

**判定规则** (vision 看 PDF jpg):
- 应证段是**文字段** (PyMuPDF get_text("blocks") 提的) → underline
- 应证段是**图表/表格** (含柱图/饼图/生存曲线/数据表) → Square 矩形框整个图表

## 2. 深黄 (1.0, 0.8, 0.0) — 用户最新偏好 (替换 B 中黄)

**用户原话**: "P3-2的PDF, highlight和图片不一致, PDF中的highlight太浅"

**之前 B 选项 RGB**:
- JPG 像素: (255, 230, 100) - 中黄
- PDF stroke: (1.0, 230/255, 100/255) ≈ (1.0, 0.902, 0.392) - 浅黄
- PDF 字节格式: `/Type/Annot/Subtype/Underline/C[1 .9019608 .39215688]`

**新 C 选项 (用户最新确认)**:
- JPG 像素: (255, 200, 0) - **深黄**
- PDF stroke: (1.0, 0.8, 0.0) - **深黄**
- PDF 字节格式: `/Type/Annot/Subtype/Underline/C[1 .8 0]`

**为什么**: underline annot 在 PDF 渲染时颜色浅 (RGB ≈ 浅黄) 在白底不显眼, 改深黄 (1.0, 0.8, 0.0) 有强烈视觉提示.

**颜色对应表**:
| 类型 | JPG RGB | PDF stroke (0-1) | PDF 字节 |
|------|---------|-----------------|---------|
| 旧 B 中黄 | (255, 230, 100) | (1.0, 0.902, 0.392) | `C[1 .9019608 .39215688]` |
| **新 C 深黄** | **(255, 200, 0)** | **(1.0, 0.8, 0.0)** | **`C[1 .8 0]`** |

**复现代码**:
```python
# 深黄 underline (paragraph)
annot = page.add_underline_annot(rect)
annot.set_colors(stroke=(1.0, 0.8, 0.0))  # 深黄

# 深黄 rectangle (chart/table)
annot = page.add_rect_annot(rect)
annot.set_colors(stroke=(1.0, 0.8, 0.0))  # 深黄矩形框
```

## 3. 真值 PDF 优先 — 用户发的 PDF 用于校对, 不擅自替换 step4

**用户原话**: "你擅自用我发你的替换当前pdf" + "且不符合P3-2定好的策略"

**之前我犯的错** (P3-1 案例):
1. 用户发了 GLOBOCAN 摘要 PDF (1 页, 含 "中国占全球 24.2%")
2. step3 P3-1 已有 main IARC PDF (2 页, 含 Asia 数据但无 China)
3. 我擅自把用户发的 PDF 复制到 step4 当真值 — **错**

**正确做法**:
- step3 有 main PDF → **用 main PDF**
- step3 没 main PDF → 用 fallback
- **不擅自添加/替换** 用户发的 PDF 到 step4
- 用户发的 PDF 用于**校对算法结果** (算法 vs 真值, 看 vision 提的应证段对不对)

**视觉配对找 main PDF 真应证** (P3-1 案例):
- PPT 视觉: "中国肝癌占全球近半数 42.5%"
- main IARC PDF page 1: "Cancer site ranking Liver (7th) 843,045 cases + Asia 70.2% 591,519 cases"
- **真应证**: "Asia 70.2% 591,519 cases" 行 (Asia 占 70.2% 全球肝癌 ≈ 中国是 Asia 主要国家, 概念对应)
- 视觉配对算法用 vision 找到这行, 不是用关键词 "中国" 找

### P3-1 — 图表矩形 (Asia 70.2% 行)

```python
# 视觉配对: Asia 70.2% Incidence 行 (vision 看 main IARC PDF page 1)
```

### P3-2 — 段落 4 行 underline

```python
# PyMuPDF get_text("blocks") 提 page 3 应证段 (y 50-170 范围, 4 行)
doc = fitz.open(pdf)
blocks = doc[2].get_text("blocks")
proof_blocks = []
for b in blocks:
    x0, y0, x1, y1, text = b[0], b[1], b[2], b[3], b[4].strip()
    if 50 < y0 < 170 and 60 < y1 < 200:
        proof_blocks.append((x0, y0, x1, y1))

# 4 行 underline (深黄)
page = doc[2]
for x0, y0, x1, y1 in proof_blocks:
    annot = page.add_underline_annot(fitz.Rect(x0, y0, x1, y1))
    annot.set_colors(stroke=(1.0, 0.8, 0.0))  # 深黄
    annot.update()
doc.saveIncr()
```

**验证**: 4 条 underline Rect pt y=633-737, jpg cluster 4 个 y=130, 179, 225, 275 ✅

## 6. 关键坑 (新增)

- `add_rect_annot` 没 `set_border_width` 方法 (会 AttributeError), 用默认边框宽度即可
- 视觉配对找图表时, bbox 要**整个图表范围** (含标题/坐标轴/图例/数据点), 不是只标数据区
- PyMuPDF `add_rect_annot` 是 Square annot (PDF Subtype=`/Square`), underline 是 Underline annot (PDF Subtype=`/Underline`), 字节 grep 时区分
