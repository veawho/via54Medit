## 5 步骤原文

### 步骤 1: PPT 目录
1. PPT 目录 (原版 + 扩页 + 扩页 jpg)
2. 文献 PDF 下载目录
3. 文献 PDF highlight 目录

### 步骤 2: 标注分析
1. 引文分两部分: 引用序号 + slide 底部对应引文
2. 视觉分析所有元素可见性, 若超出页面 → 重新扩页, **底色与文字颜色足够对比度**
3. 标号 N → PPT 内容分析 → D 列 (视觉+文字)
4. A B C 列对齐 PPT 后固定不变
5. D 列因缺 PDF 校准为暂定
6. 必视觉分析, 需 PPT 导出图片目录

### 步骤 3: PDF 下载
1. E 列 DOI (带超链接)
2. F 列下载链接 (引文完整字段 + DOI 交叉校验)
3. Pn-x 归档 (不去重), 全 PDF + 摘要 PDF
4. 全 PDF / DOI 对齐真值

### 步骤 4: Highlight
1. 复制下载目录到 highlight
2. 按 slide 顺序, 视觉分析 + 文字
3. PDF 找语义段落/数据/图标/表格, 提取匹配页面的图片
4. PPT + PDF 匹配后, PDF 加黄线
5. **多 Pn-x 1,2 / 1-3 共享综合对比**
6. 再次对照
7. 160 Pn-x 目录 + PDF + 多张截图

### 步骤 5: 三方对齐
1. (slide+mark) ↔ (A+B) ↔ (文献下载目录) ↔ (highlight 目录)
2. (引文) ↔ (C+E) ↔ (下载 PDF) ↔ (highlight PDF)
3. (视觉) ↔ (D+F+H) ↔ (highlight 图片) ↔ (D 列)

## 12 列 CSV Schema

| 列 | 字段 | 含义 |
|----|------|------|
| A | slide | slide 序号 |
| B | mark | slide 中引用序号 |
| C | citation | PPT 完整引文字段 |
| D | visual | 视觉+文字分析 (暂定) |
| E | DOI | 带超链接 DOI |
| F | download_url | 下载链接 |
| G | actual_pdf | 实际下载 PDF 文件名 |
| H | highlight_status | highlight 状态 |
| I | align_AB | A B 对齐 (100%) |
| J | align_C_PDF | C ↔ PDF 对齐 |
| K | align_D_HL | D ↔ HL 对齐 |
| L | merged_dir | 合并目录名 (Pn-x 1:1) |
