## 根因

**LLM 本质随机**:
- vision model 默认 temperature > 0 (精确值不可知)
- 同一 image + 同一 prompt, 2 次 inference 走不同 sampling path
- data_points 列表 (顺序敏感) + 数字精度 (1 位 vs 2 位) + 边界 (95% CI 与真实值混淆)

**Pydantic 不能解决内容正确**:
- Schema 强制结构, 不强制视觉事实
- Pydantic 收到一个合法 JSON, 内容可能全错

**唯一稳定方案**: 双轨 + XML 优先
- python-pptx XML 100% 稳定 (不依赖 LLM)
- Vision 仅补 XML 没有的 (chart/table data_points)
- 4 类幻觉过滤砍掉最常见 hallucination 模式

## 含义

- **不要让 subagent 重跑 vision 作为稳定性证据** — 跟原始跑的不一致率 60%, 无关
- **不要把 vision 跑出的 data_points 当 ground truth** — 必须跟 XML / 真值 / PDF 应证交叉验证
- **vision 适合"探索未知" + "验证 XML 提的"**, 不适合"独立抽数字"
- **5 行 PDF 应证数据** (Sangro 1494P + Lau Asian + George ESMO Asia + Yau Lancet) 必须用 PDF 提, vision 提不到, XML 提不到
