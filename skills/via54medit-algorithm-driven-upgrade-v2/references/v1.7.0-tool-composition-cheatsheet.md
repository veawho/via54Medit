## 5 个工具 + 能力对照

| 工具 | 能力 | 触发方式 | 何时用 |
|------|------|---------|--------|
| **Hermes Chrome Connector** | `chrome.debugger` + `chrome.scripting.executeScript`, 拟人点击 + DOM 自动化 | CDP 发 message 给 service worker (本地 127.0.0.1:16319) | Cloudflare Turnstile / 扩展 content script / 复杂表单 |
| **Unpaywall** | 监测 DOI 页, 注入 `iframe.name = "color#<URL>"` (green/bronze/gold OA) | 自动触发 (DOI 页加载后) | 任意有 Unpaywall 收录的 DOI |
| **Open in Sci-Hub** | 手动跳 sci-hub | 扩展按钮点击 / Hermes 触发 | DOI 拿不到 OA, 试 sci-hub |
| **Find sci paper by sci-hub** | sci-hub 跳转 | 手动 | backup |
| **Clash Party** | 切换 proxy / 直连 / 多 IP 出口 | AppleScript / macOS 通知 / CLI | IP-based paywall / Cloudflare 反复拦截 |

## 8 步 fallback + 工具组合地图

```
Step 1: DownloadsWatcher (CDP)
   ↓ 失败
Step 2: Unpaywall iframe (30s 轮询) + JS_SCAN
   ↓ 失败
Step 3: meta_citation_pdf_url (Runtime.evaluate DOM)
   ↓ 失败
Step 4: ASCO pdfdirect (CDP Fetch) [10.1200/*]
   ↓ 失败
Step 5: Frontiers shortcut (CDP Fetch) [10.3389/*]
   ↓ 失败
Step 6: Unpaywall API (urllib) + Europe PMC (NULL-safe)
   ↓ 失败
Step 7: Sci-Hub mirrors (Open in Sci-Hub 触发) — sci-hub.ee / .sg / .ren
   ↓ 失败
Step 8: Google filetype:pdf (CDP + 多 query 变体)
   ↓ 失败
═══════════════════════════════════════════════════════════════════
Step 9 (跳出 fallback): 工具组合救援
   ↓ 9a. Hermes 触发 Unpaywall 扩展多点几次 (用户原话)
   ↓ 9b. Hermes 触发 Open in Sci-Hub 扩展跳 iframe
   ↓ 9c. Clash Party 切 proxy IP, Chrome session 重试
   ↓ 9d. Hermes 拟人点击 Cloudflare Turnstile
   ↓ 失败
Step 10: 标记 + 汇报 — "Google filetype:pdf 救了 8 个, sci-hub.ee 救了 6 个...
       你可能需要 <某工具> 救剩余 N 个, 或人工提供 institutional access"
```

## cheatsheet: 写 Python 触发扩展

```python
# Hermes Chrome Connector 触发 Unpaywall content script
import websocket, json
tab = Tab()
# Navigate to DOI page first
tab.send('Page.navigate', {'url': f'https://doi.org/{doi}'})
time.sleep(8)
# Trigger Unpaywall extension to re-scan (Hermes 内部 message)
# 实现: chrome.runtime.sendMessage via CDP
js = '''
chrome.runtime.sendMessage('iplffkdpngmdjhlpjmppncnmhomiipha', {
    action: 'recheck_unpaywall'
});
'''
tab.eval(js)
time.sleep(5)
# Continue scanning for iframe
```

```python
# Clash Party 切 proxy (AppleScript)
import subprocess
subprocess.run(['osascript', '-e', '''
tell application "ClashX"
    set proxy mode to global
end tell
'''])
time.sleep(3)
# Now Chrome session auto uses new IP
chrome.reload_page()
```
