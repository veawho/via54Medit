---

## 核心方法论: 5 步迭代校准循环

```
代码重构 → 跑审计 → 跟真值对照 → 诊断错例 → 改代码 → 再跑
```

**别跳过对照!** 用户原话: "我已经说了, 表格中有标准答案, 你到底听没听懂?"

任何 PPT 引用算法, 写完后立即跑对照算 P/R/F1, 错例**逐个**分析 (不是整体看数字)。

## 假阳性 47 → 0 (改 1 行)

**根因**: `<= 50` 太宽, 真值最大 18, 标号 20-50 几乎全是假 (期刊年份, 表格数字, 上标 Unicode `⁴⁰⁴` 误识)。

**Fix**: `<= 18` 立刻砍掉 47 假阳性, 0 新增漏识别。

## 错配 125 个 (C 列 — 标号 → 引用)

**根因**: 启发式 1:1 配对 按出现顺序取 next 引用 ≠ 视觉对应。

**实测错误分布**:
- P3 标 1-4 全错位 (sort 升序 ≠ 视觉)
- P4 标 1-4 整组错位
- P5 标 1-9 错位 (18 条引用 vs 18 标号 数量对但配法错)

**结论**: 启发式不可能 100%, 视觉对应关系必须 vision_analyze 或读真值。

**绝对不要重算** A/B/C 列。重算 D 列时, 真值"引用语义"已经是人类视觉分析的标准答案, 直接用, 别用 vision 重跑。
