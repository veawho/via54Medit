# v1.5.1 — v13 NoneType AttributeError 3 Bug 修复

## 背景

`chrome_batch_pdf_downloader_v13.py` 是真干活的下载器 (CDP Fetch.enable 拦截 + 7 步 fallback + Unpaywall iframe 解析). 但 v13 有 3 个 **NoneType AttributeError** bug, 不修就跑不完 fallback chain.

实测: 18 个 Lancet / Nature / AACR / Elsevier DOI 在 v1.5.0 跑出 `exception: AttributeError("'NoneType' object has no attribute 'get'")` 然后 fail. 修后 84/84 = 100%.

## Bug #1: `epmc_pdf` (line 412-413) — resultList == null

```python
# 原 v13 代码 (BAD)
def epmc_pdf(doi):
    try:
        url = f'https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:{doi}&format=json'
        req = urllib.request.Request(url, headers={'User-Agent':'Mozilla/5.0'})
        with urllib.request.urlopen(req, timeout=8) as r:
            data = json.loads(r.read())
        results = data.get('resultList', {}).get('result', [])  # ← BUG HERE
        if results and results[0].get('pmcid'):
            return f'https://europepmc.org/articles/{results[0]["pmcid"]}?pdf=render'
    except Exception:
        pass
    return None
```

**触发场景**: Europe PMC API 返回:
```json
{
  "version": "6.8",
  "resultList": null,  # ← null, 不是 {}
  "citationCount": null,
  ...
}
```

**触发原因**: `data.get('resultList', {})` 当 'resultList' 存在但值为 null 时返回 None (因为 'in dict' 时 default 不生效). 然后 `None.get('result', [])` → `AttributeError: 'NoneType' object has no attribute 'get'`.

**v1.5.1 修法** (safe_epmc_pdf):
```python
def safe_epmc_pdf(doi):
    try:
        url = f'https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:{doi}&format=json'
        req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
        with urllib.request.urlopen(req, timeout=8) as r:
            data = json.loads(r.read())
        result_list = data.get('resultList') or {}  # ← None → {}
        results = result_list.get('result') or []  # ← None → []
        if results and results[0].get('pmcid'):
            return f'https://europepmc.org/articles/{results[0]["pmcid"]}?pdf=render'
    except Exception:
        pass
    return None
```

**关键**: `data.get('resultList') or {}` (没有 default) + `or {}` 处理 None.

## Bug #3: `try_download` 在 fetch_via_cdp exception 时返回 (None, None)

```python
# v13 try_download (line 221)
def try_download(tab, url, timeout=20, prefer='cdp'):
    if prefer == 'cdp':
        data, src = fetch_via_cdp(tab, url, timeout)
        if data:
            return data, src
        data2, src2 = fetch_via_urllib(url, timeout)
        if data2:
            return data2, 'urllib'
        return None, f'cdp: {src} | urllib: {src2}'  # ← src/src2 可能是 None
```

**触发场景**: 当 `fetch_via_cdp` 抛异常被 v13 内 except 捕获, 返回 `(None, f'exception: ...')`. 此时 src 是 string, OK. 但当 `fetch_via_cdp` 内部 `tab.send('Fetch.enable', ...)` 失败, **`msg.get('method')` 抛 AttributeError** (因为 msg 可能是 None 或空).

**v1.5.1 修法** (safe_try_download):
```python
def safe_try_download(tab, url, timeout=20, prefer='cdp'):
    """Never raises, always returns (data, src_string)"""
    try:
        if prefer == 'cdp':
            data, src = fetch_via_cdp(tab, url, timeout)
            if data:
                return data, src or 'cdp'
            data2, src2 = fetch_via_urllib(url, timeout)
            if data2:
                return data2, 'urllib'
            src_s = src if isinstance(src, str) else 'unknown_cdp'
            src2_s = src2 if isinstance(src2, str) else 'unknown_urllib'
            return None, f'cdp: {src_s} | urllib: {src2_s}'
        # ... else 分支同理
    except Exception as e:
        return None, f'exception: {e!r}'
```

**关键**: `src if isinstance(src, str) else 'unknown_cdp'` 兜底.

## 给未来 session 的教训

1. **JSON API 返回 null 是常态** — `data.get('key', default)` 仅在 'key' 不存在时返回 default, null 值返回 None
2. **修法**: `data.get('key') or default` (处理 null)
3. **fetch_via_cdp / try_download 必须 wrap** — v13 内部可能抛 NoneType
4. **所有 None 路径都要 None-safe** — `isinstance(x, str/bytes/dict)` 比 `x is None` 更稳
5. **fetch_one 主函数必须用 try/except 包整个流程** — 不让一个 DOI fail 影响其他
