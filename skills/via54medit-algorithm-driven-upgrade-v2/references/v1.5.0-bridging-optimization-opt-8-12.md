## Critical Pitfalls (写给 next session 必读)

1. **必须用 hermes venv python 跑测试** — `/Users/david/.hermes/hermes-agent/venv/bin/python` (3.11.15 + pytest 9.1.0). 系统 `python3` (3.9.6 + pytest 8.4.2) jsonschema 行为差异:
   - `test_validator_rejects_invalid_role` 在系统 python 假性通过 (报告 valid=True 实际 valid=False)
   - 测试脚本 `~/.medit/tests/run_all.sh` 已硬编码 venv python

2. **`test_paper_md5_consistent` 只读 `_main_` 文件** — 避免选到 `_fallback_` 或 `.old_broken` (md5 漂移假阳性)

3. **Pytest test functions return None** — 改成只调用子 test, 别 `return obj` (warning + 失败)

4. **EWMA 浮点漂移** — `pytest.approx(rel=1e-6)` 不够, 用 `abs(a - b) < 0.001` (连调 100 次后漂移 ~3e-5)
