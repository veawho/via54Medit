## 扩页三段式代码

### Step 1: 扩 PPT 页面 + 移动底部 shape

```python
from pptx import Presentation
from pptx.util import Inches

PPT = '<原始 pptx>'
PPT_EXPANDED = '<扩后 pptx>'

prs = Presentation(PPT)
NEW_H = Inches(9.5)  # 7.5→9.5, 留 2" 余量
prs.slide_height = NEW_H

# 移动所有 bottom > 7.45" 的 shape 到新底部
moved = 0
for slide in prs.slides:
    for shape in slide.shapes:
        if shape.top is None or shape.height is None: continue
        bottom = (shape.top + shape.height) / 914400
        if bottom > 7.45:
            new_top = prs.slide_height - shape.height - Inches(0.1)
            if new_top < 0: new_top = Inches(0)
            shape.top = new_top
            moved += 1

prs.save(PPT_EXPANDED)
```

**实测 P5 文本框 8.02" → 8.2"**, 7 个超出页面的 shape 全部下沉到新页面.

### Step 3: pdftoppm 输出重命名 (slide-N.jpg → slide_NNN.jpg)

`pdftoppm` 默认输出 `slide-1.jpg`, `slide-2.jpg`, **破折号** (不是下划线). 后续 vision_analyze 取 NNN 编号:

```python
for f in os.listdir(out_dir):
    if f.startswith('slide-') and f.endswith('.jpg'):
        n = int(f.split('-')[-1].split('.')[0])
        new = f'slide_{n:03d}.jpg'
        os.rename(os.path.join(out_dir, f), os.path.join(out_dir, new))
```
