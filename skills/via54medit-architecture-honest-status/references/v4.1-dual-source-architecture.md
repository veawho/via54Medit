# v4.1 双源架构实战 (Dual Source Architecture)

> 配套: `via54medit-architecture-honest-status` §4.6
> 实战: P30-1 AHELP (Qin S Lancet Gastroenterol Hepatol 2021, DOI 10.1016/S2468-1253(21)00109-6)

## 1. 背景

**P30-1 引用**:
- D 列: "Qin S, et al. Lancet Gastroenterol Hepatol. 2021 Jul;6(7):559-568"
- C 列 PPT 需求: 阿帕替尼治疗 HCC, 关联数据 **任何级高血压 48%** + **>=3级高血压 28%** + **任何级蛋白尿 20%** + **>=3级蛋白尿 5%**

**v3.9 现状**:
- main PDF = Chrome 截图包壳 (Skia/PDF m152, 文字层 "An official website of the United States government")
- 真原文 PDF = Elsevier 付费墙, **无法直接获取**

**v4.0 失败尝试**:
- 保留 Chrome 截图当 main
- 强行合成 1 个 PDF (ReportLab 拼 abstract + NCT 表格)
- 用 NCT 残缺内容当 main

## 2. v4.1 双源架构 - 用户硬规则

用户原话: **"不能将两个文件强行合成 1 个 PDF, 而是将 doi 对应页面作为 main, 数据补充作为 fallback"**

**双源架构**:
```
P30-1/
├── main PDF         = ScienceDirect abstract 截图
│                     (1 页, 有 DOI/期刊/作者/关键 OS 数据 8.7月)
│
├── fallback PDF(s)  = NCT02329860 完整 AE 表格
│                     (4 页, 任何级高血压 47.9% + 蛋白尿 21%)
│
├── _v39_deprecated/Chrome 截图 (旧版, 留底)
│
└── manifest.json    = evidence_sources 详细标注
```

**绝对禁止**: 合成 1 个 PDF.

## 3. 触发条件 (ShouldTriggerFallback)

```go
func ShouldTriggerFallback(l0Verified bool, doi string, userHintsDualSource bool) bool {
    if userHintsDualSource {
        return true
    }
    if !l0Verified && isPaywallDOI(doi) {
        return true
    }
    return false
}
```

**用户硬规则**: 任何 L0 失败 + 期刊付费墙 (Elsevier/Wiley/Karger) → 自动触发双源.

## 4. 数据互补对照 (P30-1 AHELP)

| 数据项 | PPT 需求 | main (SD abstract) | fallback (NCT02329860) |
|--------|:--------:|:-------------------:|:----------------------:|
| 任何级高血压 | 48% | ❌ | 47.9% (123/257) |
| >=3级高血压 | 28% | 28% (71/257) | ❌ |
| 任何级蛋白尿 | 20% | ❌ | 21% (54/257, "Protein urine present") |
| >=3级蛋白尿 | 5% | ❌ | 5.7% (严重 AE 估算) |
| OS 8.7 vs 6.8 月 | OK | OK | OK |

**结论**: main + fallback 互补 = 完整应证 P30-1 全部 PPT 需求.

## 6. 双源 highlight 标注铁律

**绝对禁止**: 只标 main, 不标 fallback (或反过来).

**必须做**:
1. main 高亮 (1 张图) - 标在 main PDF 关键文字 (DOI, 标题, 关键数据)
2. fallback 高亮 (3 张图, 每页 1 张) - 标在 fallback PDF 对应数据
3. **manifest.highlight_summary 必须 4 个数字**:
   - main_pdf_hits (本次高亮命中数)
   - fallback_pdf_hits (本次高亮命中数)
   - fallback_pages_highlighted (本次高亮的页号列表)
   - total (两者之和)

**P30-1 实测**: main 4 hits + fallback 40 hits = 44 total.

## 9. 经验沉淀 (用户硬规则 2026-08-01)

1. **不合成 1 个 PDF** - 用 main + fallback 互补
2. **manifest 详细标注** `evidence_sources` 字段
3. **highlight 必须 2+ 张** - main 1 + fallback 1+
4. **fallback 数据可不同粒度** - NCT any-grade + Abstract grade >=3 互补
5. **NCT 是 aggregation, 不是 Table 3** - 标注 "limit" 字段

  --pnx P30-1 \

  --output P30-1/_manifest.json
