## C列（标记）vs B列（页码）区别

```
飞书表列结构：
A = PN编号（如P23-1）  ← 目录名
B = PPT页码（=A的n值）← P23-1 → n=23 → B=23
C = 标记（PPT内引用序号）← 另一套编号系统，独立于A/B

常见混淆：B=3但A=P4-1（A的n=4不是3！→ 错误）
正确：B=P4-1的n值=4
```
