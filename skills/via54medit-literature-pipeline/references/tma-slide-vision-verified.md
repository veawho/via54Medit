## 关键教训

1. **PPT XML 文字提取不可靠** — 必须用 Sensenova vision API
2. **表格枚举编号 ≠ 文献上标** — ①②③在 aHUS 行是列表编号
3. **同一 PDF 不同页 → 不同引用上下文** — P3-1/P4-1 共享同一期刊但不同 highlight 位置
4. **vision 结果立即写入 CSV D 列** — 防止再次出错
