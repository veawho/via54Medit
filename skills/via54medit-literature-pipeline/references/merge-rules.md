# 同文献目录合并规则(2026-08-14 定稿)

> 触发: "合并 highlight 目录" / "同一文献目录合并"。
> 权威清单: 项目 `_citation_table/merge_manifest.json`(TMA 106→90 目录, 28 个 Pn-x 合并成 12 组)。
> 交付物: `文献highlight_合并后90目录.zip`(555MB / 2087 文件)。

## 合并判定标准(必须同时满足)

1. **同一文献** = 引用文本(引用表 slide/num → text)指向同一篇文献。
   - 注意: **不能只看 MD5** —— P3-1 与 P4-1 的 main.pdf 是同一文献(中华血液学杂志 2024;45(08):727-737)但 MD5/大小不同(1505KB vs 955KB, 不同下载版本), 仍要合并
   - 不能按文件名/标题去重(历史教训: 曾把同名不同论文错误合并 —— 见 via54-tma-literature-workflow Step 6 教训)
2. 合并前必须确认: 两个 Pn-x 的引用文本一致, 或同 DOI。
3. 合并**不删除**各自 highlight —— 目录合并后高亮 PDF/图片/verify 全部保留在同一新目录内, 文件名带各自 Pn-x 前缀。

## 命名规则(用户明确要求)

合并后新目录名 = 成员 Pn-x **按数字顺序**用下划线连接:

```
P3-1 + P4-1 → P3-1_P4-1
P11-2 + P12-1 + P22-2 + P25-8 → P11-2_P12-1_P22-2_P25-8
```

排序按 (slide 数字, 序号数字) 升序, 不是按合并时间/原目录出现顺序。
